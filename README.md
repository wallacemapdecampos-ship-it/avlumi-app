# Avlumi para computador 💜

Aplicativo oficial da **Avlumi** para Windows — sua comunidade com servidores, canais, voz, câmera, tela e conversas privadas.

## ⬇️ Baixar

**[» Baixar a última versão (.exe)](https://github.com/wallacemapdecampos-ship-it/avlumi-app/releases/latest)**

Na página acima, baixe o arquivo **`Avlumi-Setup-x.y.z.exe`** e abra. Pronto!

> Na primeira instalação o Windows pode mostrar um aviso azul ("Windows protegeu o computador"). É só clicar em **"Mais informações" → "Executar assim mesmo"**.

## 🔄 Atualizações automáticas

O app se atualiza sozinho: quando sai uma versão nova, ele baixa em segundo plano e instala ao reiniciar. Você não precisa baixar de novo.

## 🌐 Também funciona no navegador

Prefere não instalar? Use direto em **https://comunidade-online.onrender.com**
